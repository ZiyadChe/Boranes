Wade's Rules (PSEPT)

Two ways of counting the bonds in boranes: Lipscomb's localised styx code, then Wade's polyhedral skeletal electron pair theory.

W. N. Lipscomb, Boron Hydrides, Benjamin, 1963; K. Wade, Electron Deficient Compounds, Nelson, 1971, ch. 3; W.-K. Li, G.-D. Zhou, T. C. W. Mak, Advanced Structural Inorganic Chemistry, OUP, 2008, §13.4.
Condensed notes on the two counting schemes, drawn from Decks 4 and 6 of the full series.
Outline

Localised first, then delocalised

Part A · Lipscomb's styx code (1954 onward)

Bonds drawn as 2c and 3c pairs; three balance equations; worked examples; shortcuts for closo, nido, arachno.

Part B · Wade's rules, PSEPT (1971)

Count skeletal electron pairs; closo, nido, arachno, hypho, klado; vertex removal; carboranes.

Why this order?

The styx picture came first and uses familiar bond lines. Its electron count, p + q/2 pairs, is exactly Wade's skeletal pair count. Wade's rule then explains the shapes that styx can only describe with many resonance forms.

Lipscomb (1963); Wade (1971); R. E. Williams, Inorg. Chem. 1971, 10, 210; Li, Zhou, Mak (2008), §13.4.

styx · ground rules

Writing a borane as (BH)pHq

  • Each B has one terminal H: BpHp+q = (BH)pHq.
  • p = number of B atoms; q = number of extra H atoms.
  • B2H6: p = 2, q = 4. B5H9: p = 5, q = 4. B4H10: p = 4, q = 6.

Rules for a valid structure (Li)

(a) Every B has at least one terminal H.
(b) Neighbouring B atoms are joined by a B–B, B–H–B or B–B–B bond.
(c) Every B uses all four orbitals (an octet).
(d) Two B atoms are never joined by both a 2c B–B bond and a 3c bond.

Li, Zhou, Mak (2008), §13.4.1, rules (a)–(d); Lipscomb (1963).
The q extra hydrogens are the ones that are either bridging or the second H of a BH2 group.
styx · equations of balance

Three balances for (BH)pHq

1 · Hydrogen

s + x = q

Each extra H is either a bridge (s) or the second H of a BH2 group (x).

2 · Orbitals

s + t = p

Each B has 4 orbitals but only 3 electrons, so one orbital per B is "spare". Each 3c bond (s or t) uses one spare orbital.

3 · Electron pairs

s + t + y + x = p + q/2

Each BH unit brings 1 pair (3 + 1 − 2 for the B–H bond); each extra H brings ½ pair. Every s, t, y, x bond holds one pair.

Rearranged

x = q − s  ·  t = p − s  ·  y = (s − x)/2    → choose s, the rest follow

Lipscomb (1963); Wade (1971), eqns (3-4)–(3-6); Mingos, 50th-anniversary review (2021), Fig. 8.
Orbital balance in detail: 4p orbitals = p (terminal B–H) + x + 2s + 3t + 2y. Electron balance: (4p + q)/2 pairs = p (terminal) + s + t + y + x. Subtracting gives s + t = p. Students should derive at least the first and third.
styx · procedure

How to find the styx code

  1. Write the formula as (BH)pHq.
  2. Try each value of s in the allowed range.
  3. Calculate x = q − s, t = p − s, y = (s − x)/2.
  4. Reject negative or fractional values.
  5. Draw each survivor; keep the one that obeys the rules and the observed symmetry.

Allowed range of s

x ≥ 0 gives s ≤ q.
t ≥ 0 gives s ≤ p.
y ≥ 0 gives s ≥ x, i.e. s ≥ q/2.

q/2 ≤ s ≤ smaller of (p, q)

Wade (1971), §3-3; Das, §10.12.5 (restrictions on s); Lipscomb (1963).
The equations rarely give one answer; topology and symmetry choose among the candidates.

Why closo has y = 3

Bond valence 2t + y = 2n − 1 and pairs t + y = n + 1, so t = n − 2 and y = 3.

Why nido has s = 4

Stable nido boranes use the most bridges: neighbouring H–B–H and B–H groups become B–H–B.

Li, Zhou, Mak (2008), §13.4.4–13.4.5, eqns (13.4.4)–(13.4.21), Tables 13.4.2–13.4.3.
Derivation from the balance equations: nido q = 4 gives s + x = 4, t = n − s and y = (s − x)/2 = s − 2. Arachno q = 6 gives y = s − 3.

Part B

Wade's rules: polyhedral skeletal electron pairs

Count pairs, not bonds; the count fixes the shape.

B
Part B: PSEPT.
PSEPT · the link

From styx to Wade

  • styx needs many resonance forms for symmetric cages: 4 for B5H9, 24 for B10H14.
  • But the total number of pairs, p + q/2, does not depend on the form chosen.
  • Wade (1971) counted only these skeletal electron pairs (SEP) and related them to the shape.

The same number

BnHn+q:  SEP = n + q/2 = s + t + y + x

B5H9: 5 + 2 = 7 = 4 + 1 + 2 + 0.

Wade, J. Chem. Soc. D 1971, 792; Wade (1971), ch. 3; Mingos (2021), §7–8.
The localised and delocalised pictures agree on the electron count; Wade's version adds the link to the shape.

Which vertex is missing?

The most highly connected vertex goes first, then a neighbour of it (Williams).

Wade (1971); Williams (1971); Li, Zhou, Mak (2008), §13.4.3 (closo to hypho; B5H11²⁻ and B5H9(PMe3)2); * klado: term from later reviews, recalled.
Names: closo = closed, nido = nest, arachno = spider's web, hypho = net, klado = branch. Hypho is rare; klado rarer still.
PSEPT · justification

Why n + 1? Three orbitals per vertex

  • Each BH vertex keeps one radial sp orbital (pointing in) and two tangential p orbitals, plus 2 electrons.
  • An n-vertex cage has 3n skeletal orbitals: n radial + 2n tangential.
Wade (1971), ch. 3; Das, §10.12.7; Mingos (2021), p. 27. Schematic drawings.
B has four orbitals: one sp hybrid makes the exo B–H bond; the other sp points to the cage centre (radial); two p lie along the surface (tangential).
PSEPT · justification

B6H6²⁻: 18 skeletal orbitals, 7 bonding MOs

Das, §10.12.7; Longuet-Higgins & Roberts, Proc. R. Soc. A 1955, 230, 110; Hoffmann & Lipscomb, J. Chem. Phys. 1962, 36, 2179. Energies not to scale.
One a1g (all radial in phase) + n from tangential overlap (t1u + t2g) = n + 1 = 7 bonding MOs, filled by 14 electrons. General result for closo deltahedra: one strongly bonding radial MO plus n bonding tangential MOs. 6 BH give 12 electrons; the 2− charge supplies the last 2.

Shortcut for boranes

BnHn+mc−:  SEP = n + (m + c)/2

m + c = 2 closo · 4 nido · 6 arachno · 8 hypho

SEP = total skeletal electrons ÷ 2. Compare with n.

Quick conversion

Replace each C by B and add one negative charge: C2B10H12 ≡ B12H12²⁻; C2B4H8 ≡ B6H8²⁻ (m + c = 4: nido).

C atoms prefer low-connectivity vertices, as far apart as possible.

Summary

Key points

  • styx: s + x = q; s + t = p; s + t + y + x = p + q/2. Try each s, keep the valid, symmetric solution.
  • Shortcuts: closo (0, n−2, 3, 0); nido (4, n−4, 2, 0); arachno s + x = 6, y = s − 3.
  • Wade: n + 1, + 2, + 3, + 4, + 5 pairs → closo, nido, arachno, hypho, klado.
  • Justification: 3n skeletal orbitals give n + 1 bonding MOs for a closo deltahedron.
  • Removing vertices keeps the pair count: B6H6²⁻ → B5H9 → B4H10. C–H counts 3, so C2B10H12 is closo like B12H12²⁻.
Li, Zhou, Mak (2008), §13.4; Wade (1971), ch. 3.
Ask students to classify B9H15 and C2B9H11 2− both ways.
