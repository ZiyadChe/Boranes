Portraits for the boron slide decks
===================================
The decks look here first for a portrait (file name in the left column).
If a file is missing, they load the image from Wikimedia Commons when the
computer is online. If neither is available, they show the person's initials.

To make a portrait work offline, or to replace one, save a JPG here with
exactly this name:
